--- PROJECT DESCRIPTION ---
UniFest is a web-based Campus Event Management System designed to help 
students and staff organize, browse, and register for university events. 
It features role-based access (Admin, Staff, Student), event attendance 
tracking, and automated email notifications.

--- INSTALLATION INSTRUCTIONS ---
To run this project, please follow these steps:

1. Copy the 'UniFest' folder to your local server directory 
   (e.g., C:\xampp\htdocs\UniFest).
2. Open phpMyAdmin (http://localhost/phpmyadmin).
3. Create a NEW database named 'UniFest_db'.
4. Click 'Import' and select the 'UniFest_db.sql' file included in this folder.
5. Open your browser and go to: http://localhost/UniFest/
